it is used (CLAUDE.md "Dependency licensing"). `tests/unit/test_licenses.py` fails if a locked
Python package is missing here or is GPL/AGPL. Regenerate the Python tables with
`uv run python scripts/update_licenses.py`.

## Notes on bundled native libraries

- **Aileron Regular** (dotcolon.net, CC0 1.0) is embedded in Pillow and used through
  `ImageFont.load_default(size=…)` for the tile labels burned into mosaics (M0 step 9c).
  It is never fetched at runtime. The UI fonts (Geist, SIL OFL) are bundled with the
  frontend separately.

- **MIT-0** (cffi) is MIT without the attribution clause, so it is within the allow-list.

- **CTranslate2** (faster-whisper) Linux and Windows wheels statically link Intel oneMKL
  (Intel Simplified Software License); the Linux wheel also bundles `libgomp` (GPL-3.0 with
  the GCC Runtime Library Exception) and the Windows wheel Intel OpenMP. The macOS wheel
  links only Apple Accelerate. See ADR 0010.

- **SciPy** wheels bundle `libgfortran`, `libgcc_s` and `libquadmath`: GPL-3.0 with the GCC
  Runtime Library Exception, which permits redistribution in non-GPL software.
- **OpenCV is not used** (ADR 0008): its macOS wheels bundle a GPL FFmpeg (x264/x265).
  `tests/unit/test_licenses.py::test_no_bundled_gpl_media_libraries` scans installed native
  libraries so a dependency cannot bring GPL codecs in silently.

- **pi-heif** (HEIC/HEIF photo decoding, M1 step 9, ADR 0025) ships libheif and libde265
  (LGPL-3.0) as separate shared libraries next to its extension module, loaded
  dynamically, so they can be replaced (LGPL relinking). It is the decode-only sibling of
  pillow-heif, which is **not** used because its wheels bundle the GPL x265 encoder.
