# Voice & Copy

Plain, warm and brief. MosAic speaks like a thoughtful editor friend, not a system.

## Rules

- **Case and buttons.** Sentence case everywhere. Buttons are verbs: Create edit, Analyze, Render final, Keep, Skip.
- **Words to use.** Say footage, clip, shot, moment, edit, version, beat. Never use asset, segment, EDL, job or task outside Diagnostics.
- **Errors.** Say what happened, then give one action. Example: "Couldn't read GX020201.MP4. It looks damaged. Skip it or try again."
- **Limits.** State them honestly, with the fix. Example: "14 Insta360 360° clips will be analyzed but can't be edited yet. Export flat versions from Insta360 Studio."
- **The promise.** Show it once at project creation, verbatim: "Original footage stays where it is and will not be modified."
- **Numbers.** Timecodes, durations, costs, sizes and filenames are mono. Estimates say "About 1 h 40 m · $2–4 · 18 GB".
- **AI reasoning.** Start with the content, then the editorial reason. Example: "Drone pushes toward the waterfall through dense jungle — a strong opening shot for Day 2."
- **Never** use exclamation marks in system copy, emoji, or AI hype ("magic", "powered by AI").
