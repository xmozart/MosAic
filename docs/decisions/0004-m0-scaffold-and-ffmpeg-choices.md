# ADR 0004 — M0 scaffold, FFmpeg version and synthetic-corpus fallbacks

- **Status:** accepted (agent decision, M0 step 1)
- **Date:** 2026-10-04

## Context

`ARCHITECTURE.md §2` lists the backend modules as `backend/app/`, `backend/core/`, and so on.
Python needs an importable package name, and the CLI entry points (`mosaic`, `mosaic-dev`)
need a stable import path.

ADR 0002 B asks for an LGPL FFmpeg built for dev and BtbN LGPL builds in Linux CI. BtbN's
`latest` release only offers the 8.1 and 9.0 series, not 7.x. Frame-exact tests should run
against the same FFmpeg major version on both sides.

`EVALUATION.md §1` requires a 10-bit HEVC 59.94 synthetic case "generated in CI". The BtbN
LGPL build has no 10-bit HEVC encoder (x265 is GPL; kvazaar there is 8-bit). The macOS dev
build has `hevc_videotoolbox`, which does Main10.

`EVALUATION.md §1` also lists a HEIC + MOV Live Photo pair and a 40-hour synthetic project.
Photos arrive in M1 (ADR 0002 N), and the >3 h requirement moves to M1 (ADR 0002 C). Writing
HEIC requires an HEVC encoder in the image path (pillow-heif wheels bundle x265, which is GPL).

## Options

1. Layout: (a) a top-level package per module (`import core`), (b) `backend/` itself as the
   package (`import backend.core`), (c) one package `mosaic` under `backend/`.
2. FFmpeg: (a) dev 7.1 + CI 9.0, (b) dev and CI both on 8.1.
3. 10-bit HEVC in CI: (a) skip the case on Linux, (b) build x265 (GPL, refused),
   (c) commit a small fixture produced by the generator itself on macOS and copy it when no
   10-bit encoder exists.

## Decision

1. **(c)** The Python package is `mosaic`, rooted at `backend/mosaic/`, with subpackages
   exactly as in §2: `app, core, storage, jobs, media, audio, ai, library, editing, render,
   cli`. Developer-only code (barcode, corpus generator) lives in `mosaic.devtools`.
2. **(b)** Dev builds FFmpeg **8.1.2** (`scripts/build-ffmpeg.sh`); CI fetches BtbN
   **n8.1** LGPL (`scripts/fetch-ffmpeg-ci.sh`).
3. **(c)** `tests/fixtures/media/hevc10_5994.mov` (640×360, 4 s, Main10, 60000/1001, barcoded,
   about 280 KB) is generated by `CorpusGenerator.hevc10_5994` with VideoToolbox and committed.
   The generator copies it when the FFmpeg build lacks a 10-bit HEVC encoder.
4. The HEIC Live Photo pair and the 40-hour synthetic project are generated from M1, when
   photos and long projects are in scope. M0 generates a portrait JPEG with an EXIF
   orientation, which L0 records as a `deferred` photo.

## Consequences

- `ARCHITECTURE.md §2` is updated to show `backend/mosaic/`.
- Bumping FFmpeg means changing both scripts together.
- The 10-bit fixture is the only binary media in the repo; it is generated, not third-party.
