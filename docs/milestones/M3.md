# M3 — Mac Desktop (Tauri)

## Goal

The same app as a signed, notarized Mac application that works fully offline except for cloud AI.

## Scope

- **Tauri 2 shell** that loads the same React build.
- **First-run flow (S1):** per `docs/ui/screens/S01-first-run.md`, covering AI mode, Keychain key, and local model downloads that resume after a restart.
- **Sidecar lifecycle:**
  - launch the Python backend on `127.0.0.1` with a random port and a per-launch token
  - health wait
  - graceful shutdown that lets workers finish or checkpoint their current task
  - crash restart with job resume
- **Native folder picker.** Security-scoped bookmarks if the app is sandboxed. Otherwise document why the app is not sandboxed (ADR).
- **Local API hardening:** token on every request, Host-header check, no cross-origin access (ADR 0057: UI and API share one loopback origin, so no CORS at all).
- **Secrets** via Python `keyring` (macOS Keychain).
- **Bundling:**
  - Python via python-build-standalone or PyInstaller
  - LGPL FFmpeg with VideoToolbox
  - first-run download of the Whisper and SigLIP models, with checksum verification and a progress UI
- **Code signing, notarization and DMG** built from CI.
- **Auto-update:** Tauri updater, off by default until release signing is set up.
- **Energy and thermal awareness:** lower the worker count on battery (setting), with pause/resume from the menu bar.

## Out of scope

- Windows (a later milestone). The code must stay portable per `ARCHITECTURE.md §15`.

## Acceptance tests

1. On a clean macOS machine (the minimum version to be decided in an ADR), installing the DMG then opening a folder and running analyze → edit → render works without Python, FFmpeg or Homebrew installed.
2. A second local web page cannot call the backend (token and Host tests).
3. The API key persists across restart via Keychain and appears in no file.
4. Force-quitting during analysis and reopening resumes from the task log.
5. Project folders created by desktop open in server mode and vice versa, with no migration.

## Gate

No milestone gate. Code signing and notarization need the owner's Apple Developer ID, which falls under gate G1.

- Build and test **unsigned** first. Keep a signing step in CI that skips when credentials are missing.
- Finish everything else, then stop once with the credential request.
- If the owner defers signing, continue to M4 and keep signing as an open item.
